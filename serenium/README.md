# Serenium Finance — LinkedIn media

- `brand/` logo (400×400) and banners for the company page and personal profile.
- `tools/render.py` renders post graphics (1200×627) in the "Ledger" identity:
  `python3 serenium/tools/render.py specs.json serenium/` (layouts: concept, number, checklist, quote — see the docstring).
- `tools/fonts/` Libre Caslon Display/Text and IBM Plex Mono (SIL Open Font License, from Google Fonts).
- Post images: `serenium/Serenium-Post-YYYY-MM-DD.png`. Typographic only, no stock photos.
